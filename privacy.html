Privacy Policy

Effective November 26, 2026 (updated November 26, 2026) · Applies to The Most Unwritten Automation (the “Automation”)

The Automation is a private tool operated by the creator of the YouTube channel The Most Unwritten (“we”, “us”). It runs on our own Windows computer and is used only with our own YouTube channel. It is not offered to the public, and it does not collect data from viewers or from other YouTube users' accounts. This policy explains exactly what the Automation does with Google user data.

1. YouTube account authorization

The channel owner authorizes the Automation through Google's standard OAuth sign-in in a web browser. The Automation never sees or stores the Google account password. It requests these permissions:

Permission (scope)Why it is needed
youtube.uploadUpload finished episodes to the channel.
youtube.readonlyRead the channel's name and ID (to confirm the correct channel) and its list of recent uploads, including titles, descriptions, privacy status and scheduled publish times. This is used to prevent duplicate uploads and to find free publishing days.
youtube.force-sslManage videos the Automation uploaded: set or repair their privacy status and scheduled publish time, set their custom thumbnail, and add them to the channel's own series playlists (creating a playlist when a new series starts). After an episode goes public, it posts one comment from the channel, which the owner may pin. The Automation does not delete videos, and it does not read, edit or delete other people's comments, subscriptions or any other channel content.
yt-analytics.readonlyRead performance statistics for the channel and its videos.

2. Video uploading and scheduling

For each episode that passes quality review, the Automation uploads the video file to the channel as a private video with a scheduled publish time of 4:00 PM America/New_York. The upload includes the episode's title, description, tags and hashtags, a made-for-kids setting, and YouTube's “altered or synthetic content” disclosure, because the narration voice is AI-generated. After the upload, the Automation reads the video's status back from YouTube to confirm the schedule was stored and processing finished. It applies the episode's custom thumbnail if YouTube accepts one and adds the video to its series playlist. YouTube then publishes the video at the scheduled time. About 15 minutes later, the Automation checks that the video is public and posts the episode's discussion comment. The Automation keeps a local record of each uploaded video's ID and scheduled time.

3. YouTube Analytics data collection

Once a day, the Automation reads statistics for the channel's own published episodes from the YouTube Analytics API: views, estimated minutes watched, average view duration, average percentage viewed, likes, comment counts, shares, and subscribers gained and lost. It also reads channel totals and traffic-source totals for the last 28 days. These are aggregate numbers. They do not identify individual viewers, and the Automation does not access any viewer's personal information. The summary is stored in a single local file, which is replaced with fresh numbers each day.

4. How we use Google user data

Google user data is used only to provide the Automation's features described above: uploading, scheduling, avoiding duplicates, confirming the channel, and improving future episodes of our own channel. We do not sell Google user data. We do not use it for advertising, and we do not use it to determine credit-worthiness or for lending. We do not transfer it to anyone except as described in section 5, and no person reads it except the channel owner.

5. Data shared with OpenAI and Anthropic

OpenAI

The Automation uses the OpenAI API to write episode scripts and metadata, to generate the narration voice, to transcribe narration for accuracy checks, and to review rendered video frames. The following is sent to OpenAI:

  • our own story material: scripts, series notes, style guide, reference images, narration audio, and frames and captions of our own videos;
  • the aggregate analytics summary described in section 3, together with our episode titles, so that future scripts can improve.

No Google account credentials, tokens or viewer data are ever sent. Requests are made with response storage disabled. Under OpenAI's API data policy, API data is not used to train OpenAI's models by default; see OpenAI's Privacy Policy.

Anthropic

The channel owner uses Anthropic's Claude, in their own Claude account, to animate episodes in Roblox Studio and to maintain the Automation. Claude reads production files on our computer: scripts, quality reports, and a status file that lists our episodes' titles, YouTube video IDs and scheduled publish times. Analytics may be visible to Claude when the owner works on the Automation with it. The Automation does not send Google OAuth credentials or tokens to Anthropic. See Anthropic's Privacy Policy.

AI model training

We do not use Google user data to develop, improve or train generalized artificial intelligence or machine-learning models. OpenAI API data is not used for model training by default, and the owner keeps model training turned off in their Claude account's privacy settings, so neither provider is permitted to train on the data we send.

6. Local encrypted credential storage

After sign-in, Google returns a refresh token that lets the Automation upload without asking the owner to sign in each time. The token and the app's OAuth client credentials are stored only on our computer. They are encrypted with Windows Data Protection (DPAPI), which ties them to our Windows user account, and they are kept outside any cloud-synced folder. The original unencrypted client file is deleted once the encrypted copy has been verified. Credentials are never written to logs and never sent anywhere except Google's own sign-in and token endpoints.

If Google reports that access has been revoked, the Automation deletes the stored token and the YouTube data listed above the next time it runs. The owner can also run the Automation's disconnect command, which revokes the token with Google and deletes the same data immediately.

8. How to revoke access

You can revoke the Automation's access to your Google account at any time on the Google Account third-party connections page (also reachable at security.google.com/settings/security/permissions). Revoking stops all uploads, scheduling and analytics access immediately and triggers the deletion described in section 7.

9. Compliance

The Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube API Services Terms of Service and the YouTube API Services Developer Policies. The Automation uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

10. Security

Connections to Google, OpenAI and Anthropic use HTTPS. Credentials are encrypted at rest as described in section 6. Spending limits and an emergency stop restrict what the Automation can do automatically.

11. Children

The Automation is a production tool used only by the adult channel owner. It does not collect information from children or from anyone else.

12. Changes and contact

If we change how the Automation handles data, we will update this page and its effective date. Questions or requests: support@macrofit.info.
